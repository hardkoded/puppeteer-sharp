### ReportAnonymousScripts


```csharp
public bool ReportAnonymousScripts { get; set; }
```


Whether anonymous scripts generated by the page should be reported.

**Value:** [bool](https://learn.microsoft.com/dotnet/api/system.boolean)

Anonymous scripts are ones that don't have an associated url.
These are scripts that are dynamically created on the page using `eval` or `new Function`.
If [ReportAnonymousScripts](#PuppeteerSharp_PageCoverage_CoverageStartOptions_ReportAnonymousScripts) is set to `true`, anonymous scripts will have `__puppeteer_evaluation_script__` as their URL.

### UseBlockCoverage


```csharp
public bool UseBlockCoverage { get; set; }
```


Whether to collect coverage information at the block level.
If true, coverage will be collected at the block level (this is the default).
If false, coverage will be collected at the function level.

**Value:** [bool](https://learn.microsoft.com/dotnet/api/system.boolean)
