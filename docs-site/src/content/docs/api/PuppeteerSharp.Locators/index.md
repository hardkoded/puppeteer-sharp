Auto-waiting locators for finding and acting on elements.

## Classes

| Type | Summary |
| --- | --- |
| [Locator](/api/PuppeteerSharp.Locators/Locator/) | Locators describe a strategy of locating elements and performing an action on them. If the action fails because the element is not ready for the action, the whole operation is retried. Various preconditions for a successful action are checked automatically. |
| [LocatorActionOptions](/api/PuppeteerSharp.Locators/LocatorActionOptions/) | Options for locator actions. |
| [LocatorClickOptions](/api/PuppeteerSharp.Locators/LocatorClickOptions/) | Options for locator click actions. |
